---
title: ModuleNotFound
---





A module could not be imported, so there is nothing to document.

Raised by <PdxRef href="/api/fumero#load_module">load_module</PdxRef>. Reading a module means importing it, so it has to be installed in
the environment fumero runs in. Sitting in a directory nearby is not enough.



## Constructor Parameters [#section-constructor-parameters]

<PdxConstructor>

<PdxParameter name={"name"} type={"str"}>
The module path that could not be imported.
</PdxParameter>

</PdxConstructor>
