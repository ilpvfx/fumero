---
title: Property
---





A named, typed thing: a parameter, an attribute, or a return value.

All three read the same way on a page, so they share one shape rather than three that differ
only in which fields happen to be filled in.



## Constructor Parameters [#section-constructor-parameters]

<PdxConstructor>

<PdxParameter name={"name"} type={"str"}>
The name as written in the source.
</PdxParameter>

<PdxParameter name={"annotation"} type={"str | None"}>
The type annotation, or `None` when the item carries none.
</PdxParameter>

<PdxParameter name={"description"} type={"str | None"}>
Prose from the docstring, or `None` when the item is undocumented.
</PdxParameter>

<PdxParameter name={"value"} type={"str | None"}>
The default or assigned value as source text, or `None`.
</PdxParameter>

</PdxConstructor>
