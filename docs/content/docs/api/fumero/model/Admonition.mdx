---
title: Admonition
---





A block lifted out of a docstring to be rendered apart from the prose around it.



## Constructor Parameters [#section-constructor-parameters]

<PdxConstructor>

<PdxParameter name={"kind"} type={"str"}>
`example` for a code block, `markdown` for prose that passes through as written, or
an admonition word such as `warning`, which becomes a callout.
</PdxParameter>

<PdxParameter name={"title"} type={"str"}>
The heading the block is rendered under.
</PdxParameter>

<PdxParameter name={"content"} type={"str"}>
The body, still in markdown.
</PdxParameter>

</PdxConstructor>
