A navigation entry for something documented on a page of its own.

Carries the target's docstring as well as its name, because a list of bare names makes a reader
open every page to find the one they wanted.



## Constructor [#section-constructor-parameters]

<PdxConstructor definition={"Card(name: str, docstring: str | None = None)"}>

<PdxParameter name={"name"} type={"str"}>
The short name, used as the card's title and in its link.
</PdxParameter>

<PdxParameter name={"docstring"} type={"str | None"} value={"None"}>
The target's docstring, summarised to its first paragraph when rendered.
</PdxParameter>

</PdxConstructor>
