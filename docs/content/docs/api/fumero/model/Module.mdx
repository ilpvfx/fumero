## Constructor Parameters [#section-constructor-parameters]

<PdxConstructor>

<PdxParameter name={"name"} type={"str"}>
The short name, not the dotted path.
</PdxParameter>

<PdxParameter name={"docstring"} type={"str | None"}>
The module docstring, unparsed. A module page renders it as prose rather than
splitting it into sections the way a function page does.
</PdxParameter>

<PdxParameter name={"attributes"} type={"list[Property]"} value={"list()"} links={{"Property": "/api/fumero/model/Property"}}>

</PdxParameter>

<PdxParameter name={"classes"} type={"list[Class]"} value={"list()"} links={{"Class": "/api/fumero/model/Class"}}>
Classes documented under this module, each on a page of its own.
</PdxParameter>

<PdxParameter name={"functions"} type={"list[Function]"} value={"list()"} links={{"Function": "/api/fumero/model/Function"}}>
Module-level functions.
</PdxParameter>

<PdxParameter name={"modules"} type={"list[Card]"} value={"list()"} links={{"Card": "/api/fumero/model/Card"}}>
Child modules as navigation cards rather than whole modules, because each one is
rendered by a pass of its own instead of nested inside this one.
</PdxParameter>

</PdxConstructor>
