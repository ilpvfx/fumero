Every documented name, mapped to where it is rendered.

Behaves as a read-only mapping of path to URL, so one can be inspected, merged, or written out
by hand. Use <PdxRef href="/api/fumero/LinkTable#collect">LinkTable.collect</PdxRef> to build one from a module.



## Constructor [#section-constructor-parameters]

<PdxConstructor definition={"LinkTable(routes: Mapping[str, str] | None = None)"}>

<PdxParameter name={"routes"} type={"Mapping[str, str] | None"} value={"None"}>
An existing path to URL mapping to start from, such as one collected from another
package that this one should link into.
</PdxParameter>

</PdxConstructor>

### <span className="not-prose font-mono text-[11px] text-blue-600 dark:text-blue-400">method</span> resolve [#resolve]

</div>

<PdxFunction name={"resolve"} definition={"def resolve(path: str, scope: str | None = None) -> str | None"}>

The URL for `path`, or `None` when nothing documented goes by that name.

Resolution is scope first: a bare name is tried against `scope` before the package as a
whole, so `close` written on the `Client` page means `Client.close` rather than some
unrelated module function of the same name.





<PdxParameters>

<PdxParameter name={"path"} type={"str"}>
A name to look up. Fully qualified (`example.Client.close`), partly qualified
(`Client.close`), bare (`close`), or written against the page being rendered
(`self`, `self.close`).
</PdxParameter>

<PdxParameter name={"scope"} type={"str | None"} value={"None"}>
The name of the page being rendered, when there is one.
</PdxParameter>

</PdxParameters>


<PdxReturns type={"str | None"}>
The URL, or `None` when the path names nothing documented.
</PdxReturns>


</PdxFunction>

### <span className="not-prose font-mono text-[11px] text-blue-600 dark:text-blue-400">method</span> types\_in [#types\_in]

</div>

<PdxFunction name={"types_in"} definition={"def types_in(\n    types: Sequence[str],\n    scope: str | None = None,\n) -> dict[str, str] | None"}>

The name to URL pairs for the documented types a signature names.

This is what lets a rendered signature turn its types into links. It is given the names
the parser resolved rather than a string to search, because a name alone cannot say what
it refers to: `Path` is `pathlib.Path` in one module and a documented class in another.





<PdxParameters>

<PdxParameter name={"types"} type={"Sequence[str]"}>
Names the documented module defines, spelled as the annotation spells them.
</PdxParameter>

<PdxParameter name={"scope"} type={"str | None"} value={"None"}>
The page being rendered. It is never linked, so a class's own signature and
attributes do not link back to the page you are already reading.
</PdxParameter>

</PdxParameters>


<PdxReturns type={"dict[str, str] | None"}>
The pairs that were found, or `None` when there are none. `None` rather than an empty
</PdxReturns>


</PdxFunction>
