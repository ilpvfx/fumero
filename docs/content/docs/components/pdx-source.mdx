Written under each function when `with-source` is set, and omitted entirely otherwise. It starts
collapsed, since the source is there to be consulted rather than read through.

The block inside is an ordinary fenced code block, highlighted by the host app's own MDX pipeline
rather than by the component. Fumero sizes the fence to the content: the run of backticks it opens
with is always longer than the longest run inside, so a function that contains a fenced block of
its own does not close the block early and leave the rest of the page as prose.

## API Reference
