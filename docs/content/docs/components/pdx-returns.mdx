The `Returns:` section of a docstring, rendered inside a
[`PdxFunction`](/components/pdx-function) card.

A return value has no name to fill the left column, so its type sits on the caption's own line
rather than in a row below it. Given a row, the type ended up stranded a line beneath the word
introducing it, with empty space between the two.

It keeps the right-hand column every other type on the card sits in, so the types down a card
still line up.

## API Reference

`PdxReturns`

The value a function hands back, captioned inside its card. The type sits on the caption's line,
since a return has no name to fill the column a parameter's would.
