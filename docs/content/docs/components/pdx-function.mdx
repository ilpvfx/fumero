The card for one member.

The signature is the header, a band across the top of the card. It is highlighted in place rather
than written into the page as a fenced block, because a fenced block carries its own border,
radius, shadow and copy button. That chrome suits an example inside a docstring and not the thing
being documented.

`name` is not displayed. It labels the card for a screen reader, which would otherwise meet an
unlabelled figure.
